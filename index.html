RentDetective · 租房风险侦查 Agent 2026.07 起 · 个人实践

面向租房场景的风险识别系统：基于 104 条房源的 AI 预标注与人工复核，归纳文本和关系规则，手写 ReAct 循环结合 RAG 案例检索，输出带证据来源的调查报告。

  • 手写 ReAct 循环：最多 8 轮、4 个工具；工具调用用 CompletableFuture 控制超时，超时返回失败结果供后续处理
  • RAG 案例检索：云端 bge-large-zh-v1.5 嵌入，MySQL JSON 存储向量、应用层计算相似度；同联系方式房源整体切分，避免案例库与评测集泄漏
  • 规则引擎：17 条文本规则（16 启用、1 中性/禁用）与 2 条关系规则，结合联系方式聚类与价格核对；提供 Prompt Injection 检测工具
  • 三方案对照评测：在同一 24 条评测集上，规则 83.3%、Agent+RAG 79.2%、纯 LLM 37.5%；修复价格工具、Prompt 与评测口径后，Agent 从 45.8% 提升至 79.2%

评测集样本量较小，结果仅代表当前数据集；跨平台泛化尚未验证。
